# 데이터 타입

플러터 또는 JavaScript 와 같이, 채팅 앱 개발에서 사용하는 데이터 타입에 대해 설명합니다.

## 기본 데이터 타입

- 플러터(다트)와 같이 타입 시스템을 이용하는 언어가 있고, JavaScript 와 같이 동적 타입을 이용하는 언어가 있습니다.
- 이 문서에서는 주요 타입을 아래와 같이 정의하며 각 언어에서 적절히 매핑합니다.

- `null`: 값이 없음을 나타내는 타입
- `number`: 정수 및 실수를 포함하는 숫자 타입
- `string`: 문자열 타입
- `boolean`: 참(true) 또는 거짓(false)을 나타내는 불리언 타입
- `array`: 순서가 있는 값들의 집합을 나타내는 배열 타입
- `object`: 키-값 쌍으로 이루어진 데이터 구조를 나타내는 객체 타입.
