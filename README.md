# 오픈챗

## 개요

- 본 프로젝트는 소셜, 커뮤니티, 기타 각종 웹/앱에 사용되는 채팅 기능을 바이브코드로 개발하기 위한 프로픔프트 제공합니다.
- 많은 웹/앱에서 채팅 기능이 필요합니다. 아주 단적으로 예기해서 모든 웹/앱에 필수적인 기능이 바로 고객 상담, 문의/답변이 아닐까요? 이처럼 채팅은 매우 보편적인 기능입니다.
- 채팅 기능을 개발하는 방법은 여러가지가 있습니다. 오픈소스 솔루션을 활용하는 방법, 상용 솔루션을 활용하는 방법, 직접 개발하는 방법 등입니다.
- 본 프로젝트는 누구나 바이브코딩으로 소스 코딩없이 직접 채팅 기능을 개발 할 수 있도록, 채팅 기능 개발에 최적화된 프롬프트를 제공하는 방법을 선택했습니다.

## 주요 기능


- 1:1 채팅
- 그룹 채팅
- 채팅방 생성/삭제
- 메시지 전송/수신
- 사진/동영상/파일 전송
- 알림 기능
- 사용자 초대 기능
- 방장 기능

## 사용 방법

- 본 프로젝트를 클론합니다.
